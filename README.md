## Course description

This course identifies problems in smart cities and validates service ideas through data research. Students then learn to develop an MVP as a SaaS application using Python-based web frameworks, databases, public data, and external APIs, and deploy it to a cloud environment. They also refine the product based on real-world user testing and service metrics.

### Outline

- Part 1: Discovering Urban Problems and Learning Web Fundamentals
  - Understanding Startup Projects, SaaS, and MVPs
  - Observing Urban Problems and Identifying Opportunities
  - Identifying Users, Customers, and Urban Stakeholders
  - Conducting User Interviews and Validating Problems
  - Understanding Clients, Servers, URLs, HTTP, and Web Applications
  - Creating a Basic Web Application with Django
- Part 2: Designing and Building the Initial MVP
  - Analyzing Existing Solutions and Competing Services
  - Defining the Value Proposition and Business Model
  - Selecting the Core Features of the MVP
  - Writing User Stories and Product Requirements
  - Designing User Flows and Interface Prototypes
  - Creating Web Pages with Django Templates and Bootstrap
  - Modeling Application Data with Django Models
  - Implementing CRUD Operations and User Input Forms
  - Implementing Authentication, Authorization, and User-Specific Data
  - Integrating the Initial Project Prototype
- Part 3: Completing and Deploying the Service
  - Integrating Public Urban Data and External APIs
  - Processing CSV, JSON, and Geospatial Data
  - Implementing the Core End-to-End User Journey
  - Handling User Input, Errors, and External API Failures
  - Writing Automated Tests
  - Conducting Code Reviews and Refactoring
  - Using Continuous Integration
  - Deploying the Application and Database to the Cloud
  - Managing Environment Variables and Sensitive Information
  - Implementing Logging, Monitoring, Security, and Backups
- Part 4: Validating and Improving the Product
  - Releasing a Public Beta Version
  - Conducting User Interviews and Usability Tests
  - Collecting User Feedback and Service Usage Data
  - Defining and Interpreting Key Product Metrics
  - Prioritizing Bugs, Feature Requests, and Improvements
  - Improving the Product Based on Evidence
  - Refining the Business Model and Service Operation Plan
  - Preparing the Final Product Demonstration and Startup Pitch
  - Presenting the Final Product and Submitting the Final Report
