## Course description

This course identifies problems in smart cities and validates service ideas through data research. Students then learn to develop an MVP as a SaaS application using Python-based web frameworks, databases, public data, and external APIs, and deploy it to a cloud environment. They also refine the product based on real-world user testing and service metrics.
